# ימים טובים (Good Days)

ימים טובים היא אינטגרציה ל-Home Assistant עם כרטיס ל-Lovelace, שמראה **מה מגיע בקרוב**: שבת, חגים וצומות, ספירת העומר, ו**ימי הולדת ויארצייטים לפי התאריך העברי**, מעורבבים עם כל לוח שנה אחר שיש לכם ב-Home Assistant. לכל פריט יש ספירה לאחור חיה, בעברית או באנגלית.

[התקנה](install.md){ .md-button .md-button--primary }
[GitHub](https://github.com/bareli/good_days){ .md-button }

## מה היא עושה

- **עובדת בלי אינטרנט.** חגים, הדלקת נרות והבדלה מחושבים מקומית בעזרת [hdate](https://github.com/py-libhdate/py-libhdate), הספרייה שמאחורי "לוח השנה היהודי" של Home Assistant עצמה.
- **ישראל וחו"ל**, עם יום טוב אחד או שניים.
- **אירועי לוח שנה עם שעות.** שבת ויום טוב נמשכים מהדלקת נרות עד הבדלה, ולכן אפשר להשתמש בהם כטריגר באוטומציות.
- **תאריכים משפחתיים לפי התאריך העברי**: ימי הולדת, יארצייטים וימי נישואין, בניהול בלוח צד, כולל הכללים של אדר בשנה מעוברת ושל ל' חשוון וכסלו.
- **תזכורות** לתאריכים משפחתיים בטלפון, עם הכפתורים "ראיתי" ו"הזכר לי מחר", ומושהות בשבת וביום טוב.
- **טיימרים לשבת**: פלטה, מיחם, תאורה, מזגן וכל מכשיר עם מתג הפעלה וכיבוי, סביב הדלקת נרות והבדלה, עם פרופילים, תנאים ותצוגה מקדימה.
- **הפטרה** לכל שבת שיש לה פרשת שבוע, בנוסח ספרדי או אשכנזי.
- **צומות ועומר**: צומות עם שעות, חיישן צום וספירת העומר.
- **קישור ללוח שנה (ICS)** כדי להירשם לתאריכים המשפחתיים מ-Google Calendar או מהטלפון.
- משפטים ל-**Assist** בעברית ובאנגלית, ושני בלופרינטים.
- כרטיס שמותאם קודם כול לעברית: RTL, תאריכים עבריים, ספירה לאחור ונגישות במקלדת.

## דרישות

- Home Assistant בגרסה 2025.7 ומעלה.
- HACS להתקנה הקלה (אפשר גם להעתיק ידנית).

!!! note "שעות לפי שקיעה בגובה פני הים"
    כמו בלוחות שנה מודפסים, ימים טובים מתעלמת מהגובה מעל פני הים.
