## Problem

The sidebar, the panel and the options dialog call the product "ימים טובים". In the card picker, searching
"ימים טובים" returns only the generic "ידני" (manual YAML) card. The card is found only by typing the English
"Good", and its tile, the dialog title ("תצורת כרטיס Good Days") and the description are English
(`window.customCards` in `www/card.js`: name "Good Days", English description).

## Why it matters

The first thing a Hebrew-UI admin does after installing is look for the card by the name they see in the
sidebar. Not finding it reads as "the card did not install".

## Evidence

![Hebrew search in the card picker](https://github.com/bareli/good_days/blob/main/qa/evidence/UX-008-picker-hebrew-search.png?raw=1)

## Recommendation

Proposal for the owner: register the name and description in the HA user's language (the frontend language is
available as `document.documentElement.lang` / `hass.language` at load), e.g. name "ימים טובים (Good Days)",
description "שבתות, חגים ותאריכים משפחתיים עם ספירה לאחור." Keeping both names in the Hebrew string makes
either search work.
