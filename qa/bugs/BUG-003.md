## Summary

WCAG 2.1 AA 1.4.3 Contrast (Minimum): the text "חל בשבת / חג" ("On Shabbat / Yom Tov") is drawn in
`var(--warning-color, #ff9800)`, which Home Assistant's default light theme resolves to rgb(255,166,0). On the white card
it measures **1.96:1** at 11.2 px (card) and 11.9 px (panel); 4.5:1 is required. The warning says that a family date
collides with Shabbat, which is the reason the feature exists. The same colour is used for the timer preview
`.warn` lines ("Skipped...", "Conflict: ... is turned on and off at ..."). Those are not on screen in the dev data (no conflict or
skipped period), so that part is from the CSS only: same colour, same background, so the same ratio is expected but not measured.
Dark theme passes (8.69:1). The badge also carries an icon and words, so 1.4.1 is fine; only contrast fails.

## Steps to reproduce

1. Dashboard with the card; panel "ימים טובים" > family dates; theme light (Home Assistant default); language he; `qa_admin`.
2. Any family date whose next occurrence falls on Shabbat / Yom Tov shows the badge (card: item "יום השנה: סבתא רחל"; panel: four rows).
3. Measure computed colour against the effective background (scripts `gd-D.mjs`, `gd-F.mjs`).

## Expected

4.5:1 for text under 18.66 px (WCAG 2.1 AA 1.4.3).

## Actual

```
card  conflict badge text  ratio 1.96  fg rgb(255,166,0)  bg rgb(255,255,255)  11.2px  (light)
panel conflict             ratio 1.96  fg rgb(255,166,0)  bg rgb(255,255,255)  11.9px  (light)
dark theme, both:          ratio 8.69
```

## Evidence

Computed-style measurement in Chromium 153, alpha composited over the real ancestor backgrounds. The ratios are arithmetic.

## Likely root cause

Likely: `--warning-color` is used as a text colour; it is meant as a fill colour and is too light on white.

## Relevant files

`custom_components/good_days/www/card.js` (`.badge.conflict`), `custom_components/good_days/www/panel.js` (`.conflict`, `.warn`).

## Recommended remediation

Use the primary text colour for the words and keep the warning colour on the icon (and optionally a border or tinted background), or
darken it with `color-mix(in srgb, var(--warning-color) 55%, black)`. Re-measure in both themes.

## Regression test

A11Y-001. A unit test cannot hold it (contrast depends on the user's theme); this is a browser measurement.
