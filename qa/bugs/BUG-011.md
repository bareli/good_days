## Summary

Split out of #17 (BUG-005), whose recommended remediation included "stop swallowing remove / duplicate errors:
show `save_error` as run now does". #17's main defect (the four commands always failed) is fixed; this part was not
done. When `good_days/timers/remove` fails, the panel closes the confirmation and shows the toast **"נמחק"**
("deleted") while the timer is still in the list. When `good_days/timers/duplicate` fails, nothing is shown at all.
An admin who deletes a hot-plate timer before Shabbat is told it is gone when it is not.

## Steps to reproduce

1. qa_admin (he), 1440x900, `/good-days` > טיימרים לשבת, with a rule "כיבוי אור בסלון בלילה".
2. Make the remove call fail. Reproduced by answering `good_days/timers/remove` with
   `{"success":false,"error":{"code":"unknown_error"}}` from a Playwright `routeWebSocket` (stands in for any server
   or connection failure; the server itself was not changed).
3. On that row: מחיקה > confirm מחיקה.

## Expected

An error toast (the existing `save_error`, "השמירה נכשלה. נסו שוב.", or a delete-specific one) and the timer still
listed. Same for duplicate. Run now already does this (`run_failed`).

## Actual

Toast "נמחק"; the list still shows "כיבוי אור בסלון בלילה". Duplicate: no message.

## Screenshots

1440x900, light, Hebrew. Toast "נמחק" at the bottom while the row it claims to have deleted is still there:

![failed delete says deleted](https://github.com/bareli/good_days/blob/fix/qa-2026-09-30/qa/evidence/BUG-011-remove-failure-says-deleted.png?raw=1)

## Likely root cause

`www/panel.js` `_confirmRemoveRule`: `await this._timersCall({type:"good_days/timers/remove",...}).catch(() => null)`
then `this._toast(this._t("deleted"))` unconditionally. `_renderRuleRow` duplicate handler: same `.catch(() => null)`,
no toast. Neither checks `res.errors` either.

## Relevant files

- `custom_components/good_days/www/panel.js` (`_confirmRemoveRule`, `_renderRuleRow` "dup" button)

## Recommended remediation

On a rejected call or a non-empty `res.errors`, keep the dialog open (delete) and show `save_error`; toast "נמחק"
only on success. Duplicate: toast `save_error` on failure.
