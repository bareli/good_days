## Summary

In a real Home Assistant, an admin cannot create a timer with **הוספת טיימר**, cannot edit one, and cannot
delete, duplicate or test ("הפעלה עכשיו") any timer from the panel. Every one of these calls fails in every
UI language. Only **מתבנית** (presets), the profile / skip / master controls work. The admin sees "השמירה
נכשלה. נסו שוב." on save and "ההפעלה נכשלה." on run now; delete and duplicate fail silently (the
confirmation closes and the timer stays).

## Steps to reproduce

1. Log in as `qa_admin` (language he), open sidebar **ימים טובים** > **טיימרים לשבת**.
2. **הוספת טיימר**: name "כיבוי אור בסלון בלילה", device "אור סלון", פעולה כיבוי, מתי "בשעה קבועה...", 23:00. **שמירה**.
3. On any existing timer, click **הפעלה עכשיו**; then **מחיקה** > confirm; then **שכפול**.

## Expected

Save creates the rule; delete removes it; duplicate copies it; run now runs it (README *Shabbat timers*,
plan TMR-001 / TMR-004). The same messages sent without `language` succeed (below), so the server logic is fine.

## Likely root cause

Proven by the frames above: `_timersCall` in `www/panel.js` (line ~1218) adds
`language: langOf(this._hass)` to every timers message, but the schemas of `timers/save`, `timers/remove`,
`timers/duplicate` and `timers/run` in `websocket_timers.py` do not declare `language` (only `get`,
`settings` and `preset` do), so HA's websocket schema rejects the extra key. Tests presumably call these
commands without `language`, which is why CI is green.

## Relevant files

- `custom_components/good_days/www/panel.js` (`_timersCall`, and the `.catch(() => null)` on remove / duplicate that hides the failure)
- `custom_components/good_days/websocket_timers.py` (schemas at lines ~115, 151, 169, 201)

## Recommended remediation

Either add `vol.Optional("language"): cv.string` to those four schemas, or send `language` only to `get`,
`settings` and `preset`. Add a websocket test that sends each timers command exactly as the panel does
(with `language` and `entry_id`). Also stop swallowing remove / duplicate errors: show `save_error` as
run now does.
