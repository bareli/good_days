## Summary

Family names are usually typed in Hebrew. With the UI and entity text in English, titles built as
`"Yahrzeit: " + name + " (17)"` and `name + "'s birthday (37)"` are reordered by the bidi algorithm: the count and
the apostrophe are pulled into the Hebrew run, so the card shows "Yahrzeit: (17) סבא משה" and "'דני s birthday (37)".
A reader sees the year count on the wrong side of the name.

## Steps to reproduce

1. Add family dates with Hebrew names: yahrzeit "סבא משה" 22 Tishrei 5770; birthday "דני" 20 Tishrei 5750.
2. Set the HA user's language to English; open a dashboard with the Good Days card (the card editor preview shows the
   same).

## Expected

"Yahrzeit: סבא משה (17)" displayed in logical order, the user-typed name isolated from the surrounding text.
Sources: SPEC §6.4 ("Bidi: wrap mixed number/unit fragments with Unicode isolates"), plan I18N-001 ("no
mixed-direction garbling").

## Actual

Card rows: "Yahrzeit: (17) סבא משה", "Yahrzeit: (7) סבתא רחל", "'דני s birthday (37)".

## Evidence

WS `good_days/dates/list` with `language: en` returns `"title": "Yahrzeit: סבא משה (17)"`: the logical order is right,
there are no isolates, and the reordering happens at display time.

## Screenshots

1280 px, light theme, English UI, first card of the QA dashboard.

![English card with reordered titles](https://github.com/bareli/good_days/blob/main/qa/evidence/BUG-009-english-titles-reordered.png?raw=1)

## Likely root cause

`FamilyEvent.title()` (family.py) concatenates the user-typed name without FSI / PDI isolates, and the card / panel
render the title as plain text with no `<bdi>` or `dir="auto"` around the name. Likely; confirmed only by the render.

## Relevant files

- `custom_components/good_days/family.py` (`FamilyEvent.title`)
- `custom_components/good_days/www/card.js`, `www/panel.js` (title rendering)

## Recommended remediation

Decide where to isolate. Server-side isolates around the name (as escapes in source, per the conventions test) fix
card, panel, HA calendar, ICS and notifications at once; client-side `<bdi>` fixes only the UI. The same applies to
Latin names in the Hebrew UI ("יום הולדת לGrandpa Sam").

## Regression test

I18N-001: the English card shows the count after the name for "Yahrzeit: סבא משה (17)".
