## Summary

In a Hebrew UI every day header of the card shows the Hebrew date with Western digits ("21 בתשרי", "22 בתשרי"),
while the same card's expanded details and the panel show gematria ("כ״ב תשרי תשפ״ז"). Every Hebrew-UI household
sees the mixed style on every card.

## Steps to reproduce

1. HA user language Hebrew; a dashboard with `type: custom:good-days-card` (any config).
2. Open the dashboard; expand any item (for example a yahrzeit).
3. Compare the day header's Hebrew date with the one in the expanded details.

## Expected

Gematria, as in the rest of the product. Sources: SPEC §6.2 ("Hebrew date small underneath: "א׳ תשרי""),
`qa/PROJECT.md` *Locale* ("Hebrew dates in gematria (ט״ו תשרי תשפ״ז)"), and the code's own intent: it requests
`he-IL-u-ca-hebrew-nu-hebr` (Hebrew numerals).

## Actual

Header: "22 בתשרי". Details of an item on that day: "כ״ב תשרי תשפ״ז" (the server's `hebrew_date`).

## Evidence

Chromium 153 (Playwright), the same call the card makes:

```
new Intl.DateTimeFormat('he-IL-u-ca-hebrew-nu-hebr',{day:'numeric',month:'long',timeZone:'UTC'})
  .format(new Date(Date.UTC(2026,9,3,12)))                  -> "22 בתשרי"
resolvedOptions().numberingSystem                            -> "latn"
resolvedOptions().locale                                     -> "he-IL-u-ca-hebrew"   (nu-hebr dropped)
Intl.supportedValuesOf('numberingSystem').includes('hebr')   -> false
```

`hebr` is an algorithmic numbering system; ECMA-402 only supports simple-digit systems. Firefox and Safari were not
tested; I'm speculating they drop it too, per the spec.

## Screenshots

1280 px, light theme, Hebrew UI. Day headers "20 בתשרי", "21 בתשרי"; the expanded yahrzeit's details read
"כ״ב תשרי תשפ״ז".

![day headers with digits, details with gematria](https://github.com/bareli/good_days/blob/main/qa/evidence/BUG-008-day-header-digits-vs-details-gematria.png?raw=1)

## Likely root cause

`www/card.js` `_hebrewDayLabel()` relies on the `nu-hebr` locale extension, which Intl ignores (proven above for
Chromium).

## Relevant files

- `custom_components/good_days/www/card.js` (`_hebrewDayLabel`, around line 381)
- `custom_components/good_days/www/panel.js` already has a `gematriaDay()` helper

## Recommended remediation

In Hebrew, take the day number and month name from the Intl Hebrew-calendar `formatToParts` and render the day in
gematria (reuse the panel's `gematriaDay`), for example "כ״ב תשרי". English unchanged.
